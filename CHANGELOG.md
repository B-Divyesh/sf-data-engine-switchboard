# Changelog

All notable changes to Data Engine Switchboard are documented here. The project follows semantic versioning.

## 0.1.0 — 2026-08-28

- Add the `switchboard init` and `switchboard assess` CLI commands.
- Run Pandas and Polars transforms on bounded local CSV and Parquet fixtures.
- Compare value, schema, order, null, float, and timezone semantics.
- Sample runtime and peak process RSS and inspect Polars streaming plans.
- Emit human-readable and stable JSON go/no-go reports with documented exit codes.
- Include a three-incompatibility seeded suite and product documentation site.
