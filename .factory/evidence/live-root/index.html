Three steps

Check a migration in three steps

  1. 01

    Choose both transformation functions

    Point one TOML file at matching Pandas and Polars functions.

  2. 02

    Run a bounded local fixture

    The command rejects a fixture over its declared limit before it imports your code.

  3. 03

    Read the migration decision

    Measured differences decide the result. Streaming warnings remain separate.
